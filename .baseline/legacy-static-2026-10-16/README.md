# Baseline estatico anterior a consolidacao

Snapshot criado em 2026-10-16 antes da migracao deste diretorio para a fonte Next.js.

O snapshot contem todos os arquivos de implementacao e configuracao da versao Vite/HTML. A pasta `public/` nao foi duplicada porque os assets permanecem no mesmo caminho e nao fazem parte da refatoracao estrutural.

Para recuperar a versao anterior, copie os arquivos desta pasta para a raiz do projeto e restaure as dependencias com `npm ci`.

Arquivos gerados (`dist/`) e dependencias instaladas (`node_modules/`) nao fazem parte do baseline.
